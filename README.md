# 空の色と光の散乱

太陽をドラッグして、日中と夕方の空の色を調べる授業用シミュレーションです。HTML / CSS / Canvas / JavaScriptのみで動き、外部ライブラリ・外部画像・APIキーは不要です。

## 起動

このフォルダーで次を実行して、http://localhost:8000 を開きます。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

JavaScriptモジュールを使うため、index.htmlの直接ダブルクリックではなくHTTPサーバーで開いてください。

## 操作

- 太陽を直接ドラッグして移動します。地球と同心円の軌道上を動き、位置によって日中と夕方を比較できます。
- 余白を1本指（またはマウス）でドラッグするとパン、2本指のピンチでズームと移動ができます。太陽から始めたドラッグ中も、2本目の指を置くとピンチに切り替わります。
- マウスホイールと「＋・−」でも50〜400%に拡大縮小できます。ピンチは指の中点、ホイールはカーソル位置を基準にします。「表示を戻す」は倍率と移動だけを初期状態に戻し、太陽の位置は維持します。
- 「太陽側の空」では散乱を含む空、「太陽の光」では散乱せず直接届く太陽光の模式図を表示します。RGBの割合表示は削除しました。
- 「見え方を表示」で観測者から見た空をキャンバス上に重ねて表示します。初期状態は非表示です。再度ボタンを押すか、オーバーレイの「×」、Escapeキーで閉じられます。太陽を隠しにくいよう、太陽と反対側に表示します。
- 黄色の線は太陽から観測者への直線経路。大気内の区間を太く示し、頭上の太陽の場合に対する距離の倍率を表示します。
- 「?」でモデルの説明を開けます。
- 太陽をキーボードで選び、矢印キーで移動、Homeで頭上に戻せます。タッチ操作はPointer Eventsを使用します。

## 物理モデルと限界

- 赤650 nm、緑530 nm、青450 nmの3色を等確率で放出し、散乱係数は `1/λ⁴` に比例させています。光は太陽から全方向に放出され、大気内の移動距離に応じた `1 − exp(−βL)` の確率で方向を変えます。地球にぶつかった光は停止します。
- 大気は地球半径の34%の厚さを持つ一様な球殻の2次元断面。実際より厚く、太陽の距離・地球・人・粒・光速も表示のために変更しています。光の粒は毎秒地球半径の0.8倍の速さで進みます。軌道は表示領域に応じて決まり、実際の天体運動ではありません。
- 空の色は視線上の各点で太陽からの減衰、散乱、観測者までの減衰を積分した単一散乱モデルです。太陽の光は直接光の減衰だけを計算します。
- 粒のアニメーションはランダムな可視化で、見え方は解析モデルによる表示です。模式図の空は色の違いが見えるよう明るさも正規化しています。実際の輝度・色度は再現しません。
- 多重散乱、波長の連続分布、実際の色覚、大気密度の高度変化、雲、ちり、屈折は省略しています。夕方の空全体が一様に赤くなることを意味しません。
- 描画解像度は最大2倍、粒数は最大3,500個、描画は色別にまとめ、背景はキャッシュします。非表示中は進行を止め、画面復帰時の時間飛びを防ぎます。

参考：[NASA Space Place — Why Is the Sky Blue?](https://spaceplace.nasa.gov/blue-sky/en/)、[NASA Earth Observatory — Crepuscular Rays and Light Scattering](https://science.nasa.gov/earth/earth-observatory/crepuscular-rays-and-light-scattering-150090/)
